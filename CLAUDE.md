# Claude Code instructions for Whetstone

Follow [AGENTS.md](AGENTS.md) completely. It opens with the document map.

1. Read the top of [README.md](README.md), down to Install, for what
   Whetstone is, and
   [planning/direction.md](planning/direction.md) for the fixed decisions,
   before planning.
2. Find current work with `bd ready`. Beads tracks this project's tasks
   only; it is not part of the product.
3. Run the three gates in AGENTS.md before every push, and never use
   `--no-verify`.

Do not restore removed modules, commands, fixtures or compatibility paths.
Preserve `whetstone/rulebook.json`, `.beads/` and `.git/info/exclude`.
